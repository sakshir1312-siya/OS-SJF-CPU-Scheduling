Experiment overview

When the CPU becomes free, non-preemptive SJF selects the arrived process with the smallest burst time. Once selected, that process runs until it completes.

EXPERIMENT MANUAL

Aim & Theory

Aim

To simulate Non-Preemptive Shortest Job First CPU scheduling and calculate completion time, turnaround time and waiting time.

Theory

CPU scheduling selects a process from the ready queue. SJF chooses the process with the smallest burst time among processes that have already arrived. Non-preemptive means the selected process runs until completion. If no process has arrived, the CPU remains idle until the next arrival.

Formulae

CT = Completion Time
TAT = CT − AT
WT = TAT − BT
Average WT = Total WT ÷ Number of processes
Average TAT = Total TAT ÷ Number of processes

Procedure

1. Enter process arrival and burst times.
2. Find the arrived, unfinished processes.
3. Select the available process with the shortest burst time.
4. Run it until completion.
5. Repeat until all processes finish.
6. Calculate and analyse the results.
